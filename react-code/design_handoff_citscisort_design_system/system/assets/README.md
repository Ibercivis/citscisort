# Assets

- `logo.svg` — CitSci Sort wordmark + mark (designed in-house; the source repo's `public/vite.svg` was the default Vite starter logo, **not** a CitSci brand mark).
- `logo-mark.svg` — icon-only mark for favicons, avatars, sidebar collapsed state.
- `favicon.svg` — same as `logo-mark.svg`, re-exported for use as `<link rel="icon">`.

**Icons**: the source app uses **Material Icons** (`@mui/icons-material`) throughout. In this design system, icons are loaded from the [Material Symbols](https://fonts.google.com/icons) CDN (Rounded, filled, 24px) — the closest 1:1 match. See `README.md` → ICONOGRAPHY.
