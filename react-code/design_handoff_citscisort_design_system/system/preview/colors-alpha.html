Alpha overlays — the interaction vocabulary

Hover, selected, and focus states are painted with alpha on the primary or a neutral black. Never use a solid tint — the transparency lets the surface underneath show through consistently across contexts.

Generic hover
rgba(0, 0, 0, 0.04)
Used on: Table rows, menu items, list items
Card hover (darker)
rgba(0, 0, 0, 0.03) + text.disabled border
Used on: Classification option cards (unselected hover)
Selected fill
rgba(25, 118, 210, 0.08)
Used on: Selected classification card, navigation active item
Selected hover
rgba(25, 118, 210, 0.13)
Used on: hover-over-selected card
